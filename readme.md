# Feriados Chile

PWA con los feriados de Chile: cuánto falta para el próximo, calendario, fines de semana largos,
planificador de vacaciones y calculadora de días hábiles. Se instala en el celular y funciona sin
internet. Datos de la [API de feriados de Boostr](https://docs.boostr.cl/reference/holidays-info).

```bash
npm run serve   # http://localhost:8080
npm test        # pruebas de la lógica
npm run pages   # regenera las páginas /2013/ … /2027/ desde la API
```

Detalles, reglas y cómo publicar: [AGENTS.md](AGENTS.md).
